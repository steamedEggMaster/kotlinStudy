## 🎯 Kotlin ▪ Spring Boot 코프링 프로젝트 💻

이 프로젝트는 **Kotlin**과 **Spring Boot**를 이용해 백엔드를 구성하며 학습한 내용을 포함하고 있습니다.  
YouTube 강의를 통해 다양한 기능들을 구현하며 배운 기술을 담고 있습니다.

### 📚 학습한 기능들
1. **p6spy**: 개발 환경에서 쿼리 로깅
2. **Kotlin-Faker**: 무작위 객체 생성
3. **Extension Function**: 코틀린의 강력한 기능
4. **JDSL**: 최신 Spring Boot 3.x.x 이상 지원
5. **AOP**: 요청 내용 로깅
6. **Spring Security + JWT**: 인증과 인가
7. **Embedded Redis**: DB 접근 캐싱
8. **Embedded S3**: 객체 스토리지 구성
9. **Enum ↔ DB 변환**: Annotation을 활용한 변환
10. **@Scheduled + @EnableScheduling**: 메서드 스케줄링
