## Kotlin ▪ SpringBoot 코프링 💻

이 프로젝트는 Youtube 강의를 통해 Kotlin ▪ SpringBoot를 이용하여 백엔드를 구성하고, 

다양한 기능들에 대해 구현하며 공부한 내용을 담았습니다.

### 공부한 기능들
1. 개발 환경에서의 쿼리 로깅을 위한 p6psy
2. 편리하게 무작위 객체를 생성해주는 Kotlin-Faker
3. 코틀린의 장점인 Extension Function
4. SpringBoot 3.x.x 버전 이상에서의 JDSL
5. AOP를 통한 요청 내용 로깅
6. SpringSecurity와 JWT를 통한 인증 ▪ 인가
7. Embedded Redis를 이용한 DB 접근 캐싱
8. Embedded S3를 이용한 객체 스토리지 구성
9. Annotation을 활용한 Enum Class ↔ DB 데이터 간의 변환
10. @Scheduled + @EnableScheduling 을 이용하여 메서드 스케줄링
